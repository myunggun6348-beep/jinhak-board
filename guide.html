3시작하기

크롬이나 엣지에서 jinhak-board.vercel.app을 엽니다.

혼자 쓰기

  1. 첫 화면에서 혼자 쓰기

    다음부터는 그 컴퓨터에서 첫 화면 없이 바로 열립니다.

  2. 위쪽 담당 반을 고르기

    2반 같은 반 단추를 누릅니다.

  3. 지원 현황 파일 넣기

    아래 4. 지원 현황 넣기를 보세요. 이제 바로 쓰면 됩니다.

관리자: 학교 만들기

  1. 관리자입니다 → ① 구글로 로그인

    평소 쓰는 구글 계정으로 로그인합니다. 관리자에게는 따로 암호가 없고 구글 로그인이 그 역할을 합니다.

  2. ② 학교 이름과 가입 암호를 정하고 학교 만들기

    학교 이름은 화면 위에 보이는 이름표일 뿐이라 정식 명칭이 아니어도 되고, 나중에 전체 현황 맨 아래에서 바꿀 수 있습니다. 가입 암호(4자 이상)는 지금 새로 정하는 암호로, 담임 선생님이 가입할 때 한 번만 넣습니다. 초대 링크가 다른 사람에게 가도 이 암호 없이는 못 들어옵니다. 구글 비밀번호를 넣지 마세요. 학교 코드는 따로 정하지 않습니다(저절로 생김).

  3. 학교 코드는 적어만 두기

    K7QM-3XPA처럼 8자리 코드가 나옵니다. 이 컴퓨터는 기억하고, 담임은 초대 링크에 코드가 들어 있어 칠 일이 없습니다. 관리자가 다른 컴퓨터에서 열 때만 학교 코드로 열기에 넣습니다(전체 현황 맨 아래에서 다시 볼 수 있음).

  4. 초대 링크 복사 → 담임들께 학교 메신저로

    가입 암호는 링크와 따로(말이나 문자로) 알려 주세요. 둘 다 있어야 가입 요청이 됩니다.

  5. 가입 요청 승인

    요청이 오면 화면 위에 승인 대기 N이 뜹니다. 누르면 전체 현황 맨 아래로 가고, 담당 반을 확인해 승인합니다.

  6. (필요하면) 관리자 더하기

    전체 현황 맨 아래 관리자 추가에 다른 관리자의 구글 이메일을 넣습니다.

담임: 가입하기

  1. 관리자가 보낸 초대 링크를 크롬·엣지에서 누르기

    학교 코드는 저절로 들어갑니다. 링크가 없으면 선생님입니다에서 코드를 직접 넣어도 됩니다(소문자·하이픈 상관없음).

  2. 이름·담당 반·가입 암호를 넣고 가입 요청

    담당 반은 목록에서 고릅니다. 이 반 학생만 보게 됩니다.

  3. 관리자 승인 기다리기

    "관리자 승인을 기다리는 중입니다"가 뜹니다. 승인되면 화면이 저절로 열립니다.

  4. 우리 반 지원 현황 파일 넣기

    처음 한 번만 넣으면 됩니다. 다른 반 학생이 파일에 섞여 있어도 우리 반만 들어갑니다.

구글 로그인이 안 될 때 — Claude 앱 안의 창처럼 팝업을 막는 곳에서는 구글 로그인이 되지 않습니다. 크롬·엣지 같은 일반 브라우저로 여세요.

4지원 현황 넣기 (처음 한 번)

학생 목록 아래 명단·지원 현황 넣기에서 넣습니다. 진학 프로그램에서 뽑은 표를 그대로 넣으면 됩니다.

① 파일에서

PDF·엑셀(.xlsx)·CSV·한글(.hwpx) 파일을 화면 아무 데나 끌어다 놓거나 파일 선택. 대학·모집단위·전형·면접일·발표일·최저 여부를 알아서 읽습니다.

② 붙여넣기

엑셀이나 한글의 표를 복사해 화면에서 Ctrl+V. 칸 이름이 달라도 알아봅니다.

③ 한 명씩

학번·이름을 직접 넣고, 학생 카드에서 + 수시 지원 추가로 한 건씩 넣습니다.

서식이 필요하면

명단 서식·지원 현황 서식을 받아 채운 뒤 넣으면 가장 정확합니다.

알아 두세요 — 같은 파일을 다시 넣어도 학생·지원이 늘어나지 않고 갱신됩니다. 입력해 둔 합격 결과는 지워지지 않습니다. 구형 한글(.hwp)은 열 수 없으니 한글에서 다른 이름으로 저장 → .hwpx로 바꿔 넣으세요. 잘못 넣었으면 바로 나오는 ↶ 파일 넣기 취소를 누르세요.

7전체 현황 · 학교 관리

위쪽 전체 현황 탭입니다. 관리자는 모든 반을, 담임은 자기 반만 봅니다.

반별 현황 · 정시 현황

반마다 학생·지원·합격·충원·경고 수와 정시 군별 지원.

지원 현황 (대학별·학과별)

대학이나 학과를 누르면 지원 학생이 나옵니다. 막대로 많이 지원한 곳이 보입니다.

수능최저 기준 점검

'최저 있음'만 있고 기준 문장이 없는 지원 목록. 목록 복사로 모아 요강에서 채웁니다.

진학 실적

학년 말 보고용. 실적 엑셀(CSV) 받기.

학교 관리 (관리자, 맨 아래)

학교 코드 보기·복사, 초대 링크 복사, 가입 암호 정하기·바꾸기, 가입 승인·거절, 담당 반 바꾸기, 선생님 빼기, 관리자 추가.

8자료 지키기 · 옮기기

9자주 묻는 질문

화면이 이상하거나 새 기능이 안 보여요

Ctrl+F5로 새로고침하세요. 앱은 자주 고쳐지고, 새로고침하면 최신으로 바뀝니다.

구글 로그인 단추를 눌러도 반응이 없어요

팝업이 막힌 창입니다(Claude 앱 안의 창 등). 크롬·엣지에서 열고, 주소창 오른쪽에 팝업 차단 표시가 있으면 허용하세요.

가입 암호가 맞지 않는다고 나와요

관리자에게 암호를 다시 확인하세요. 관리자가 암호를 바꿨을 수도 있습니다. 이미 승인된 선생님은 암호가 바뀌어도 그대로 씁니다.

다른 반 학생이 안 보여요

담임은 담당 반만 봅니다. 반이 바뀌었으면 관리자에게 반을 바꿔 달라고 하세요. 모든 반을 봐야 하면(진학부장 등) 관리자로 추가돼야 합니다.

학교 코드가 꼭 필요한가요?

학생 자료는 학교 코드로 잠가서 저장하기 때문에(저장소의 구글도 못 읽게) 코드가 곧 열쇠입니다. 그래도 직접 칠 일은 거의 없습니다. 학교를 만든 컴퓨터는 저절로 열리고, 담임은 초대 링크로 들어오면 코드가 이미 들어가 있습니다. 관리자가 새 컴퓨터에서 열 때만 한 번 넣습니다.

학교 코드를 잃어버렸어요

관리자는 전체 현황 맨 아래 학교 코드 → 보기에서 다시 볼 수 있습니다. 관리자 모두가 잃어버리면 자료를 열 수 없으니 꼭 적어 두세요.

여럿이 쓰는 컴퓨터에서 써도 되나요

가입할 때 이 컴퓨터에 코드 기억을 끄고, 다 쓰면 위쪽 나가기를 누르세요. 혼자 쓰기는 공용 컴퓨터에서 쓰지 마세요.

휴대폰에서도 되나요

보기와 결과 고치기는 됩니다. 파일 넣기·인쇄는 PC가 편합니다. 혼자 쓰기 자료는 그 기기에만 있어 PC와 휴대폰이 따로입니다.

수능최저가 '판정 못함'으로 나와요

요강 문장에 선택 조건(또는·혹은)이 있거나 탐구 과목을 몰라서입니다. 학생 카드에서 이유를 보고, 필요하면 최저 기준 문장을 직접 고치세요. 학교 장부에서는 고친 기준이 다른 반의 같은 지원에도 쓰입니다.

10개인정보와 보안

암호화해서 저장

학교 장부의 학생 자료(이름·학번·대학·성적)는 학교 코드로 이 컴퓨터에서 암호화한 뒤 저장됩니다. 저장소(구글)도 내용을 읽을 수 없습니다. 학교 이름, 선생님 이름·반, 관리자 이메일은 암호화되지 않습니다.

세 겹으로 막기

학교 코드 + 가입 암호 + 관리자 승인. 담임은 자기 반만, 다른 학교는 서로 볼 수 없습니다. 관리자가 빼면 그 즉시 막힙니다.

지켜 주세요

초대 링크와 가입 암호는 학교 메신저로 따로 보내기. 담임 메모에 건강·가정사 같은 민감한 내용은 쓰지 않기. 입시가 끝나면 학교 규정대로 정리하기. 관리자 구글 계정은 2단계 인증 켜기.

학교 규정 확인 — 학생 정보를 외부 서비스에 저장하므로 학교 개인정보 담당 선생님께 "암호화해서 저장한다"고 알려 두시길 권합니다.
