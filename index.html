진학 현황판 사용 설명서

담임 선생님

  1. 관리자가 학교 메신저로 보낸 초대 링크를 크롬·엣지에서 누릅니다.
  2. 이름·담당 반과, 관리자에게 따로 받은 가입 암호를 넣고 가입 요청. (링크가 없으면 선생님입니다 → 학교 코드를 직접 넣어도 됩니다.)
  3. 관리자가 승인하면 화면이 저절로 열립니다. 담당 반 학생만 보입니다.
  4. 처음 한 번, 우리 반 지원 현황 파일(PDF·엑셀·한글)을 화면에 끌어다 놓습니다.
  5. 그다음부터는 학생 이름을 눌러 결과(합격·충원대기·불합격)만 바꾸면 됩니다. 저장은 자동입니다.

관리자 (진학부장 등)

  1. 관리자입니다 → ① 구글로 로그인 → ② 학교 이름·가입 암호 정하기 → 학교 만들기.
  2. 초대 링크 복사로 링크를 학교 메신저로 보내고, 가입 암호는 따로(말·문자) 알려 줍니다. 화면의 학교 코드는 관리자가 적어 둡니다.
  3. 가입 요청이 오면 화면 위 승인 대기 → 담당 반을 확인하고 승인.
  4. 관리자는 모든 반을 봅니다. 위쪽 학교 관리 탭에서 가입 승인·반 바꾸기·빼기·관리자 추가를 합니다.

혼자 쓰기

  • 첫 화면에서 혼자 쓰기를 고르면 로그인 없이 그 컴퓨터(브라우저)에만 저장합니다. 다음부터는 바로 열립니다.
  • 브라우저 기록을 지우면 자료도 지워집니다. 위쪽 막대가 주황색이 되면 지금 백업 받기를 누르세요(7일이 지났거나, 결과가 바뀌었거나, 많이 고쳤을 때). 받은 파일을 화면에 끌어다 놓으면 되살아납니다.
  • 나중에 위쪽 학교 장부로를 누르고 학교에 들어가면, 이 브라우저 자료를 올릴지 묻습니다.

휴대폰 홈 화면에 추가

  • 안드로이드(크롬): 위쪽 앱으로 설치, 또는 메뉴 ⋮ → 홈 화면에 추가.
  • 아이폰(사파리): 아래 공유 단추 □↑ → 홈 화면에 추가.
  • 컴퓨터(크롬·엣지): 주소창 오른쪽 설치 아이콘이나 위쪽 앱으로 설치. 바탕화면 아이콘으로 바로 열립니다.

알아 둘 것

  • 학교 코드를 잃어버리면 자료를 열 수 없습니다. 관리자는 학교 관리 탭에서 다시 볼 수 있습니다.
  • 여럿이 쓰는 컴퓨터에서는 '코드 기억'을 끄고, 다 쓰면 위쪽 학교 이름 옆 나가기.
  • Claude 앱 안의 창에서는 구글 로그인이 막힙니다. 크롬·엣지로 여세요.
  • 화면이 이상하면 Ctrl+F5(새로고침).

학생

명단·지원 현황 넣기

명단이나 지원 현황 파일을 여기에 끌어다 놓으세요 PDF · CSV · 엑셀 · 한글(.hwpx)을 읽습니다. 표를 복사해 Ctrl+V 로 붙여넣어도 됩니다. 다른 선생님이 보낸 반 파일(.json)은 여러 개를 한꺼번에 넣으면 합쳐집니다.

한 줄에 한 명. 학번과 이름 사이는 띄어쓰기, 탭, 쉼표 무엇이든 됩니다. 한글 표를 복사해 붙여넣어도 읽습니다.

서식이 필요하시면 지원 현황은 상태·전형 값이 정해져 있어 서식을 쓰시는 편이 안전합니다.
